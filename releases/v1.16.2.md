Fixes the pale border around the app icon in Finder, Spotlight and the About panel.

- Compiles the selected Asteroid Duel artwork as a native macOS icon composition, allowing the system to apply the correct shape and spacing.
- Bundles the native asset catalog and all standard and Retina compatibility icon sizes for macOS 13+ and the mounted DMG.
- Removes the separate runtime Dock icon override so Finder, Spotlight and the running app use the same bundled icon.

Apple Silicon only, macOS 13 or newer. Building, signing and notarization run locally.
